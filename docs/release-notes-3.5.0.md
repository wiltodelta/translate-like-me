Translate Like Me 3.5.0

- Added local dictation. Hold right Option while speaking, then release to recognize and insert at the cursor. You can choose left Option in Settings.
- Automatically detects the speech model's supported languages, including Russian and English. Uses the microphone selected in macOS, with no account or API key required.
- Enable dictation in Settings > General, allow microphone access and download the speech model once. Recognition then runs on your Mac. Temporary recordings are deleted after use; Copy Last Dictation keeps the latest result available during the current session.
